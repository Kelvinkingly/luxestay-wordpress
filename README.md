# LuxeStay — Luxury Hospitality Platform

[![LuxeStay homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/luxestay-homepage.jpg)](https://luxestay-knowedge.infinityfreeapp.com/)

[Visit live website](https://luxestay-knowedge.infinityfreeapp.com/)

Independent WordPress portfolio platform by KnowEdge Business Development Services Ltd. Luxury editorial design, editable accommodation listings, responsive navigation, stay planning, guest-capacity filters, indicative price estimates, FAQs and concierge links.

No real hotel inventory, reservations, payments or personal records are collected. Rates and imagery are illustrative.

## Install

Zip the `theme/luxestay` folder including its top-level directory. Upload through WordPress Appearance → Themes and activate. Initial room records are seeded once.
